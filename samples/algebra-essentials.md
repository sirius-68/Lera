# Expressions

## Collecting like terms

An expression is a collection of numbers and letters joined by operations, such as $3x + 4$. Each part separated by a plus or minus sign is called a term.

Like terms are terms with exactly the same letters and powers. $3x$ and $5x$ are like terms. $3x$ and $5$ are not, and neither are $3x$ and $5x^2$.

To collect like terms, add the numbers in front and keep the letter part the same:

$$3x + 5x = 8x$$

Remember: only like terms can be added together. The expression $2x + 3$ cannot be made any simpler.

Example 1: Simplify $4x + 7 - x + 2$.

$$4x - x + 7 + 2$$

$$3x + 9$$

### Exercises

Simplify each expression.

1. $5x + 3 + 2x + 4$
2. $7x - 2 - 3x + 9$
3. $4x^2 + 3x - x^2 + 5x$
4. $6a + 2b - 4a + 3b$

## Expanding brackets

A number in front of a bracket multiplies every term inside it. This is the distributive property.

$$3(x + 2) = 3x + 6$$

A minus sign in front of a bracket changes the sign of every term inside:

$$-(x - 5) = -x + 5$$

Example 2: Expand and simplify $4(x + 2) - 3(x - 1)$.

$$4x + 8 - 3x + 3$$

$$x + 11$$

### Exercises

Expand and simplify.

1. $3(x + 4)$
2. $-2(x - 5)$
3. $5(2x + 1) - 3(x - 2)$
4. $2(x + 3) + 4(x - 1)$

## Laws of exponents

An exponent tells you how many times a number or letter is multiplied by itself. In $x^3$ the base is $x$ and the exponent is 3.

When you multiply powers of the same base, add the exponents:

$$x^2 \cdot x^3 = x^5$$

A power of a power multiplies the exponents:

$$(x^2)^3 = x^6$$

Note: a power outside a bracket applies to everything inside it, so $(2x)^3 = 8x^3$.

### Exercises

Simplify.

1. $x^4 \cdot x^2$
2. $(x^3)^2$
3. $(3x)^2$
4. $2x^3 \cdot 5x^2$

# Linear Equations

## Solving linear equations

An equation is a statement that two expressions are equal. Solving an equation means finding the value of the unknown that makes it true.

The rule is to do the same thing to both sides. To undo an addition, subtract. To undo a multiplication, divide. These are called inverse operations.

Example 3: Solve $3x + 4 = 19$.

$$3x = 15$$

$$x = 5$$

Tip: check your answer by substituting it back into the original equation.

### Exercises

Solve each equation.

1. $x + 7 = 12$
2. $3x = 21$
3. $2x - 5 = 9$
4. $4x + 3 = 2x + 11$
5. $7 - x = 10$

## Equations with brackets and fractions

If an equation has brackets, multiply them out first. If it has fractions, multiply every term on both sides by the common denominator.

Example 4: Solve $2(x + 3) = 14$.

$$2x + 6 = 14$$

$$2x = 8$$

$$x = 4$$

### Exercises

Solve for x.

1. $3(x - 2) = 12$
2. $-2(x - 3) = 8$
3. $\frac{x}{3} + 2 = 5$
4. $5(x + 1) = 3x + 11$

## Linear inequalities

An inequality compares two expressions using the signs $<$, $>$, $\le$ or $\ge$. It is solved like an equation, with one extra rule.

Important: when you multiply or divide both sides by a negative number, the inequality sign reverses.

Example 5: Solve $7 - 3x \le 16$.

$$-3x \le 9$$

$$x \ge -3$$

### Exercises

Solve each inequality.

1. $2x + 1 > 9$
2. $-4x < 12$
3. $5 - 2x \ge 11$

# Quadratics

## Expanding two brackets

To multiply two brackets, every term in the first bracket multiplies every term in the second.

$$(x + 3)(x - 2) = x^2 - 2x + 3x - 6 = x^2 + x - 6$$

Squaring a bracket means multiplying it by itself. A binomial is an expression with two terms.

$$(x + 3)^2 = x^2 + 6x + 9$$

### Exercises

Expand and simplify.

1. $(x + 4)(x + 1)$
2. $(x - 3)(x + 5)$
3. $(x + 2)^2$
4. $(2x + 1)(x - 4)$

## Factorising quadratics

Factorising is the reverse of expanding. A quadratic is an expression where the highest power of the unknown is 2.

To factorise $x^2 + bx + c$, find two numbers that multiply to give $c$ and add to give $b$.

Example 6: Factorise $x^2 + 5x + 6$.

$$(x + 2)(x + 3)$$

### Exercises

Factorise.

1. $x^2 + 7x + 12$
2. $x^2 - 5x + 6$
3. $x^2 - 9$
4. $2x^2 + 6x$

## Solving quadratic equations

If a product is zero, then one of its factors must be zero. So once a quadratic is factorised, each bracket gives a solution.

Example 7: Solve $x^2 - x - 6 = 0$.

$$(x - 3)(x + 2) = 0$$

$$x = 3 \text{ or } x = -2$$

Remember: an equation like $x^2 = 9$ has two solutions, because both 3 and $-3$ square to give 9.

### Exercises

Solve each equation.

1. $(x - 4)(x + 1) = 0$
2. $x^2 + 5x + 6 = 0$
3. $x^2 = 16$
4. $x^2 = 3x$
5. $x^2 + 3x - 1 = 0$
