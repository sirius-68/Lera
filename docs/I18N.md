# Languages

Lera speaks English, French and Russian. It follows the phone's language (French or Russian when the phone
is set to one of them, English otherwise) unless a language is picked in Settings.

## How a line gets translated

English is written in the code, and is also the key the translation is filed under.

| In the code | When to use it |
| --- | --- |
| `t('Next lesson')` | A line shown on screen. |
| `t('Part {n} of {total}', { n, total })` | A line with values in it. The whole sentence is one line, so each language can order it its own way. |
| `tn(count, '{n} day ago', '{n} days ago')` | A line that depends on a count. Russian keeps its three forms under the plural line as `one|few|many`. |
| `msg('Morning')` | A line written in a table at the top of a file, before the language is known. It marks the line; the screen that shows it calls `t(row.label)`. |
| `localized(table)` | A whole table of marked lines (a concept, say) in the app's language. |
| `promptText(problem.prompt)` | A problem's instruction. The stored instruction stays in English. |

Text that is not the app's own (the learner's notes, their working, AI answers) is never passed through these.

## The dictionaries

`src/i18n/fr.ts`, `ru.ts` (the tabs) and `fr.more.ts`, `ru.more.ts` (everything else).

## The check

`npm run i18n` reads the code, lists every line that goes through `t`, `tn` or `msg`, and fails if one has
no French or Russian entry, or if a translation names different values from its English. The app build runs it,
so an untranslated or reworded line cannot ship unnoticed. `node scripts/i18n-check.mjs --unused` lists
dictionary entries no line uses any more.
